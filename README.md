# FinTracker 📈

FinTracker — це комплексний веб-застосунок для відстеження фінансових активів та криптовалютного портфеля. Платформа надає потужні інструменти для моніторингу інвестицій, візуалізації ефективності портфеля та глибокої аналітики даних.

## 🌟 Основні можливості

* **Управління портфелем:** Зручне додавання, редагування та відстеження різних фінансових активів (криптовалюти, акції, фіатні кошти).
* **Просунута аналітика:** Використання Pandas для розрахунку ефективності портфеля та побудови кореляційних матриць активів.
* **Асинхронні задачі:** Автоматичне оновлення курсів валют та регулярна генерація аналітичних звітів у фоновому режимі.
* **RESTful API:** Повноцінний API для інтеграції із зовнішніми інтерфейсами та сервісами.
* **Експорт даних:** Формування детальних звітів та їх надійне зберігання в системі.

## 🛠 Стек технологій

* **Backend:** Python 3, Django, Django REST Framework
* **Data Science / Аналітика:** Pandas
* **Фонові задачі:** Celery, Celery Beat, Redis
* **База даних:** PostgreSQL
* **Інфраструктура:** Docker, Docker Compose

## 🚀 Встановлення та запуск (Docker)

Проєкт повністю контейнеризований, що робить процес розгортання швидким та зручним.

1. **Клонуйте репозиторій:**
```bash
git clone [https://github.com/ken1x/fintracker.git](https://github.com/ken1x/fintracker.git)
cd fintracker
```

2. **Налаштуйте змінні оточення:**
Скопіюйте шаблон конфігурації та вкажіть необхідні дані (паролі до БД, API-ключі):
```bash
cp .env.example .env
```

3. **Запустіть контейнери:**
```bash
docker-compose up -d --build
```

4. **Застосуйте міграції:**
```bash
docker-compose exec web python manage.py migrate
```

5. **Створіть суперкористувача (опціонально):**
```bash
docker-compose exec web python manage.py createsuperuser
```

Застосунок буде доступний за адресою: `http://localhost:8000/`.

## 📂 Структура проєкту

* `config/` — основні налаштування проєкту Django.
* `tracker/` — головний додаток (бізнес-логіка, моделі, серіалізатори, представлення).
* `media/reports/` — директорія для зберігання згенерованих аналітичних звітів.
* `docker-compose.yml` / `Dockerfile` — конфігурація контейнеризації застосунку.
* `celerybeat-schedule` — розклад для періодичних фонових задач.
* `main.py` / `manage.py` — точки входу в застосунок.
